# Optional Qwen weights

The default configuration looks for `Qwen_Qwen3.5-9B-Q4_K_M.gguf` here.
Obtain the model separately and record its source, license and SHA-256 checksum.
No download URL, model license, or particular quantization provenance is assumed
by this release. An alternative GGUF path can be supplied with `--model-path`.

`template` is an explicitly different backend, not evidence for LLM performance.
